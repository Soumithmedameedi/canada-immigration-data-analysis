# Canada-immigration-data-analysis
Exploratory analysis of Canada immigration trends from 1980–2013 using Python, Pandas, NumPy, and Matplotlib. Includes data cleaning, country-level analysis, India vs. China comparison, top contributing countries, continent-level aggregation, and data visualization.
# Canada Immigration Data Analysis

## 📌 Project Overview

This project explores historical immigration data to Canada from 1980 to 2013 using Python and Pandas.

The analysis focuses on understanding immigration trends across countries and continents, with specific analysis of India, China, top contributing countries, and regional patterns.

## 🎯 Objectives

- Analyze immigration trends over time
- Explore country-level immigration patterns
- Analyze India's immigration trend
- Compare India and China
- Identify the top contributing countries
- Analyze immigration by continent
- Create visualizations to identify trends and patterns

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- JupyterLab

## 🔍 Analysis Performed

### Data Preparation
- Loaded the Canada immigration dataset
- Inspected dataset structure and columns
- Renamed columns for clarity
- Created a `Total` immigration column
- Checked data quality
- Set `Country` as the DataFrame index

### Exploratory Data Analysis

- Filtered country-level data using `.loc[]`
- Analyzed India's immigration trend
- Compared India and China
- Ranked countries based on total immigration
- Grouped immigration data by continent
- Examined distributions and trends

## 📊 Visualizations

The project includes:

- Line charts
- Bar charts
- Horizontal bar charts
- Area charts
- Histograms
- Pie charts
- Box plots
- Scatter plots
